`pnp-core` is the official TypeScript SDK for the [PnP protocol](https://www.pnp.exchange/) on
Solana. It wraps the on-chain program in one clean, type-safe client so you can create markets,
take positions, settle, and redeem without hand-rolling instructions or account resolution.

## How it fits together

Everything hangs off a single **`PnpClient`**, which exposes three namespaces:

| Namespace | What it does | Model |
|-----------|--------------|-------|
| `client.p2p` | Parimutuel markets — create, buy, settle, redeem, refund, criteria | V3 |
| `client.amm` | Pythagorean markets — create + read prices/multipliers | V2 |
| `client.oracle` | Read the AI oracle's resolvable-status and settlement criteria | — |

PnP markets vary along **two independent axes** — pick one from each:

| Axis | Options |
|------|---------|
| **Liquidity model** | `p2p` (parimutuel / creator seeds a side) · `amm` (Pythagorean / seeded liquidity) |
| **Resolution kind** | general question · coin/token price · YouTube stats |

<Note>
`pnp-core` is a from-scratch rewrite of the older `pnp-sdk`. The client is now `PnpClient`
(constructed from an options object) and methods are grouped under `p2p` / `amm` / `oracle`
instead of living flat on the client.
</Note>


`pnp-core`. Node 18+ is required.

## Construct a client

Use the `mainnet()` / `devnet()` presets, or the full constructor for custom RPC and commitment.

<Tabs>
  <Tab title="Node (Keypair)">
    ```ts
    import { PnpClient } from "pnp-core";
    import { Keypair } from "@solana/web3.js";
    import { readFileSync } from "node:fs";

    const wallet = Keypair.fromSecretKey(
      Uint8Array.from(JSON.parse(readFileSync("/path/to/id.json", "utf8"))),
    );

    // Preset (uses the network default RPC)
    const client = PnpClient.mainnet({ wallet });

    // …or the full constructor
    // const client = new PnpClient({
    //   cluster: "mainnet",
    //   wallet,
    //   rpcUrl: "https://your-rpc.example.com",
    //   commitment: "confirmed",
    // });
    ```
  </Tab>
  <Tab title="Browser (wallet adapter)">
    ```ts
    import { PnpClient } from "pnp-core";
    import { useWallet } from "@solana/wallet-adapter-react";

    // `wallet` is any adapter exposing publicKey + signTransaction(s).
    const { wallet } = useWallet();

    const client = PnpClient.devnet({
      wallet,
      rpcUrl: "https://your-rpc.example.com",
    });
    ```
  </Tab>
  <Tab title="Read-only (no signer)">
    ```ts
    import { PnpClient } from "pnp-core";

    // Omit `wallet` for reads/derivations only. Write methods throw.
    const client = PnpClient.mainnet();

    const market = await client.p2p.getMarket(42n);
    console.log(market.impliedYesProbability);
    ```
  </Tab>
</Tabs>

## Your first calls

Reads need no wallet; writes need a signer.

```ts
import { PnpClient, uiToBaseUnits } from "pnp-core";

const client = PnpClient.mainnet({ wallet });

// READ — decode a market by numeric id or PDA
const market = await client.p2p.getMarket(42n);
console.log(market.question, market.impliedYesProbability);

// WRITE — create a parimutuel market seeded with 100 USDC on YES
const res = await client.p2p.createMarket({
  question: "Will BTC close above $100k on Dec 31, 2026?",
  initialAmount: uiToBaseUnits(100, 6), // amounts are in BASE units
  side: "yes",
  endTime: new Date(Date.now() + 30 * 864e5),
});
console.log("market id:", res.marketId.toString());
```

<Warning>
**Amounts are always in base units, not UI units.** For 6-decimal USDC, 100 USDC is
`100_000000n`. Use `uiToBaseUnits(100, 6)` / `baseUnitsToUi(amount, 6)` to convert.
</Warning>
