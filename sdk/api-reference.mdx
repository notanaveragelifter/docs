Import everything from the package root:

```ts
import { PnpClient, uiToBaseUnits, pda /* … */ } from "pnp-core";
```

<Info>
On-chain read/write methods accept a market as a numeric **id** (`bigint | number`) **or** its
**`PublicKey`** PDA. Oracle (indexer) methods accept a `PublicKey | string`. **Amounts are in
base units** — use `uiToBaseUnits` / `baseUnitsToUi`.
</Info>

## PnpClient

| Member | Signature | Notes |
|--------|-----------|-------|
| constructor | `new PnpClient(opts: PnpClientOptions)` | `cluster` required; omit `wallet` → read-only |
| `PnpClient.mainnet` | `(opts?) => PnpClient` | mainnet preset |
| `PnpClient.devnet` | `(opts?) => PnpClient` | devnet preset |
| `.p2p` | `P2PModule` | parimutuel / V3 API |
| `.amm` | `AmmModule` | Pythagorean / V2 API |
| `.oracle` | `OracleModule` | indexer / oracle reads |
| `.canSign` | `boolean` | true if a signer is attached |
| `.payer` | `PublicKey` | signer pubkey; throws if read-only |
| `.requireWallet()` | `() => AnchorWallet` | returns the signer or throws |
| `.signMessage(msg)` | `(Uint8Array) => Promise<Uint8Array>` | ed25519 sign for off-chain auth |

Also exposed as properties: `network`, `connection`, `programId`, `program` (the underlying
anchor `Program`), `provider`, `commitment`, `wallet?`, `criteriaApiUrl`, `oracleApiUrl`.

<ParamField path="cluster" type='"mainnet" | "devnet"' required>
  Target network. Set automatically by the `.mainnet()` / `.devnet()` presets.
</ParamField>
<ParamField path="wallet" type="Keypair | AnchorWallet">
  A Node `Keypair` or browser wallet adapter. Omit for a read-only client.
</ParamField>
<ParamField path="rpcUrl" type="string">
  Override the network default RPC endpoint.
</ParamField>
<ParamField path="connection" type="Connection">
  Provide a preconfigured `@solana/web3.js` connection instead of `rpcUrl`.
</ParamField>
<ParamField path="commitment" type="Commitment" default="confirmed">
  Transaction commitment level.
</ParamField>
<ParamField path="criteriaApiUrl" type="string">
  Override the settlement-criteria server base URL.
</ParamField>
<ParamField path="oracleApiUrl" type="string">
  Override the indexer API base URL (include the `/api` prefix).
</ParamField>

## client.oracle — indexer reads

| Method | Signature |
|--------|-----------|
| `getResolvableStatus` | `(market: PublicKey \| string, opts?) => Promise<ResolvableStatus>` |
| `getSettlementCriteria` | `(market: PublicKey \| string, opts?) => Promise<OracleSettlementCriteria \| null>` |

`ResolvableStatus` = `"checking" | "resolvable" | "unresolvable"`.
`waitForResolvable` options: `{ apiUrl?, intervalMs? (3000), timeoutMs? (120000) }`.

## Helper functions

<AccordionGroup>
  <Accordion title="Numeric & units">
    - `toBN(value) => BN`
    - `toBig(value) => bigint`
    - `u64le(value) => Buffer` — 8-byte little-endian
    - `uiToBaseUnits(amount, decimals) => bigint` — `uiToBaseUnits(100, 6) === 100_000000n`
    - `baseUnitsToUi(amount, decimals) => number`
  </Accordion>
  <Accordion title="Token & ATA">
    - `getTokenProgramForMint(connection, mint) => Promise<PublicKey>` — classic vs Token-2022
    - `ata(mint, owner, tokenProgram?) => PublicKey` — associated token address
    - Constants: `TOKEN_PROGRAM_ID`, `TOKEN_2022_PROGRAM_ID`, `ASSOCIATED_TOKEN_PROGRAM_ID`
  </Accordion>
  <Accordion title="PDAs (pda.* namespace)">
    Each is `(programId, id) => PublicKey` unless noted:
    - `pda.globalConfigPda(programId)`
    - `pda.marketV2Pda`, `pda.marketV2ExtensionPda`
    - `pda.marketV3Pda`, `pda.yesMintV3Pda`, `pda.noMintV3Pda`, `pda.marketV3ExtensionPda`, `pda.marketV3GatePda`
    - `pda.creatorFeeTreasuryPda(...)`, `pda.reserveVault(...)`
  </Accordion>
  <Accordion title="Settlement-criteria signing">
    - `buildSettlementCriteriaMessage(params) => string`
    - `sha256Hex(input) => string`
    - `randomNonce() => string`
  </Accordion>
  <Accordion title="Networks & IDL">
    - `resolveNetwork(cluster) => NetworkConfig`
    - `NETWORKS` — `{ mainnet, devnet }`
    - `getIdl(cluster) => Idl`, `PNP_IDL_MAINNET`, `PNP_IDL_DEVNET`, `IDL_PROGRAM_ADDRESS`
  </Accordion>
</AccordionGroup>

## Key types

### P2PMarket

Decoded + computed snapshot returned by `p2p.getMarket`. Token amounts are `bigint` base units.

```ts
interface P2PMarket {
  address: PublicKey;
  id: bigint;
  question: string;
  status: "open" | "ended" | "resolved";
  creator: PublicKey;
  creatorSide: "yes" | "no";
  creatorInitialAmount: bigint;
  resolved: boolean;
  resolvable: boolean;
  winner: "yes" | "no" | null;
  endTime: number;          // unix seconds
  creationTime: number;
  yesPot: bigint; noPot: bigint; totalPot: bigint;
  yesTokensIssued: bigint; noTokensIssued: bigint;
  impliedYesProbability: number; // 0..1
  impliedNoProbability: number;  // 0..1
  collateralMint: PublicKey; yesMint: PublicKey; noMint: PublicKey;
  creatorFeeTreasury: PublicKey;
  hasExtension: boolean; oddsBps: number; oracle: PublicKey | null;
}
```

### AmmMarket

```ts
interface AmmMarket {
  address: PublicKey; id: bigint; version: number;
  question: string; status: "open" | "ended" | "resolved";
  creator: PublicKey; resolved: boolean; resolvable: boolean;
  winner: "yes" | "no" | null;
  endTime: number; creationTime: number;
  collateralMint: PublicKey;
  yesMint: PublicKey | null; noMint: PublicKey | null; // null until first buy
  marketReserves: bigint; yesSupply: bigint; noSupply: bigint; initialLiquidity: bigint;
  creatorFeeTreasury: PublicKey;
  yesPrice: number; noPrice: number; yesMultiplier: number; noMultiplier: number;
}
```
